# Rant Math

Math on Rant's standard types: poses, shapes, fits, cameras, images and point clouds.

```csharp
using Rant.Math;
using Rant.Types;
using UnityEngine;

Double3 position = transform.position.ToRant();
```

Add it beside `com.rant.rant`, or beside `com.rant.types` in a project with no Rant.
